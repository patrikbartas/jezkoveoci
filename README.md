# /\\/\\/\\(•.•)> Ježkove oči

Jednoduchý web pre OZ Ježkove oči – komunitnú cyklodielňu BANM v Bratislave.

Žiadne frameworky, žiadne závislosti, žiadne trackery. Len ježko.

ASCII ježko je prvý krok k novej vizuálnej identite – kompletný nový web
občianskeho združenia okolo tejto tematiky je v pláne. Návrhy loga žijú
v `ascii-logo-navrh.md`.

## Funkcie

- oči sa otáčajú smerom ku kurzoru
- prepínanie light/dark režimu kliknutím na ježka
- ASCII logo ježka pri odkaze na 2 % a v pätičke 2% stránky
- stránka `2percenta.html` s informáciami k poukázaniu 2 % z dane
- základné SEO meta informácie pre OZ Ježkove oči

## Súbory

- `index.html` - štruktúra stránky + SEO meta + favicon
- `2percenta.html` + `2percenta.css` - stránka k 2 % z dane
- `styles.css` - layout, light/dark téma, responzívny vzhľad
- `main.js` - logika sledovania kurzora a prepínania témy
- `ascii-logo-navrh.md` - návrhy ASCII loga ježka
- SVG assety (`jezko_bez_oci.svg`, `lave-oko.svg`, `prave-oko.svg`, `favicon.svg`)
